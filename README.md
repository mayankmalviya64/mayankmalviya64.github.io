# Mayank Malviya’s portfolio

Default portfolio: https://mayankmalviya64.github.io/beyond-my-cv/

GitHub Pages publishes the `main` branch from the repository root.
`beyond-my-cv/index.html` contains the portfolio; shared styles, scripts, and
images remain in `style.css`, `script.js`, and `assets/` at the repository root.

The root URL and `/my-portfolio/` redirect to `/beyond-my-cv/`, preserving query
parameters and section anchors when JavaScript is enabled. Without JavaScript,
a meta refresh and a visible link take visitors to the new portfolio home.
